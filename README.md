Student Management System

A simple Student Management System built using Python and SQLite. This project allows users to add and view student records through a command-line interface.

Features

- Add student details
- View student records
- SQLite database integration
- Simple and beginner-friendly project
-  Technologies Used

- Python
- SQLite

Project Structure

student-management/
│
├── database.py
├── operations.py
├── main.py
└── students.db

 How to Run

Step 1: Create Database

python database.py

Step 2: Run Application

python main.py

Sample Output

1. Add Student
2. View Students
3. Exit
